# Anotacoes do piloto

Usar anotacoes leves e versionaveis sempre que possivel.

Classe recomendada por frame:

- `main_goal`;
- `secondary_goal`;
- `not_goal`.

Campos minimos sugeridos:

```json
{
  "image": "match_01_000120.500.jpg",
  "match_id": "match_01",
  "timestamp": 120.5,
  "label": "main_goal",
  "visibility": "full",
  "polygon": [[1000, 300], [1210, 290], [1220, 710], [990, 720]],
  "quality": "ok",
  "notes": ""
}
```
