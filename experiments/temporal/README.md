# V9 — Consistência temporal

Preencha `temporal_sequences_template.csv` com trechos reais de 3–5 segundos.
Os campos `start_seconds` e `end_seconds` devem ser convertidos a partir do
tempo exibido no vídeo. Não usar os timestamps isolados do piloto como se fossem
sequências.

Use `goal_structure` para trechos em que uma goleira principal ou secundária
permanece visível e `not_goal` para trechos sem estrutura de goleira.
